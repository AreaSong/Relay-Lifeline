# 前端字体许可

控制台自托管以下 Adobe 开源字体，均依据 SIL Open Font License 1.1 使用：

- `SourceHanSansCN-VF.woff2`：思源黑体简体中文变量字体，许可证见 `OFL-SourceHanSans.txt`。
- `SourceSans3VF-Upright.woff2`：Source Sans 3 变量字体，许可证见 `OFL-SourceSans3.txt`。
- `SourceCodeVF-Upright.woff2`：Source Code Pro 变量字体，许可证见 `OFL-SourceCodePro.txt`。

字体文件与许可证均取自 Adobe Fonts 官方 GitHub 仓库的 `release` 分支；前端不从 CDN 加载字体。
